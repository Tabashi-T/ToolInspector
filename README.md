# ToolInspector

Десктопное приложение для поиска сколов на фотографиях режущего инструмента.
Работает локально, без интернета и внешних API.

## Как это работает

Двухступенчатый анализ:

1. **EfficientNet-B0** быстро классифицирует фото: *пригоден* / *брак*.
2. Если уверенность классификатора ниже порога (`YOLO_TRIGGER = 0.60` в `ai_analyzer.py`),
   фото передаётся в **YOLOv8n**, который находит точное положение сколов и рисует рамки.

Интерфейс: [customtkinter](https://github.com/TomSchimansky/CustomTkinter).

## Структура проекта

```
ToolInspector/
├── main.py               # точка входа
├── ui.py                 # интерфейс
├── ai_analyzer.py        # EfficientNet + YOLOv8: обучение и анализ
├── augment_dataset.py    # аугментация (зеркало и поворот на 180°)
├── prepare_dataset.py    # labelme JSON -> формат YOLO, обрезка фона
├── debug_dataset.py      # проверка разметки (рисует рамки на примерах)
├── tools/
│   └── export_dataset.py # подготовка датасета к публикации (очистка метаданных и JSON)
├── requirements.txt
├── LICENSE
├── weights/
│   └── best.pt           # обученные веса YOLOv8n (детектор сколов)
└── training_results/     # метрики и графики одного из запусков обучения YOLOv8
```

Датасет лежит в папке `DataAI/`. В репозитории хранятся только исходные фото и разметка:

```
DataAI/
├── good/      # фото годных инструментов
└── defect/    # фото с дефектами + разметка labelme (.json рядом с каждым фото)
```

Остальное (`augmented/`, `yolo_dataset/`, `debug_preview/`, `results/`, `model_weights/`)
создаётся скриптами проекта и находится в `.gitignore`.

## Публикация датасета

Из полной локальной папки `DataAI` публикуемая копия собирается скриптом
(исходная папка не изменяется):

```bash
python tools/export_dataset.py "D:\путь\к\полной\DataAI" --forbid Фамилия НазваниеОрганизации
```

Скрипт копирует только `good/` и `defect/`, вырезает EXIF из фото, убирает из JSON
встроенные картинки (base64) и абсолютные пути, ищет подозрительные имена файлов
и в конце подсказывает, хватит ли обычного Git по размеру.

## Подготовка данных и обучение

1. Положите фото годных инструментов в `DataAI/good/`, фото с дефектами в `DataAI/defect/`.
2. Разметьте сколы прямоугольниками в [labelme](https://github.com/wkentaro/labelme)
   (`pip install labelme`), JSON сохраняйте рядом с фото.
3. Аугментация для EfficientNet (по желанию):
   ```bash
   python augment_dataset.py
   ```
4. Датасет для YOLO:
   ```bash
   python prepare_dataset.py
   python debug_dataset.py      # проверить, что рамки легли правильно
   ```
5. Запустите приложение и нажмите **«Переобучить»**:
   ```bash
   python main.py
   ```
   Будут обучены обе модели, веса сохранятся в `DataAI/model_weights/`.

## Использование

1. Нажмите **«Выбрать фото»**.
2. Нажмите **«Запустить анализ»**.
3. Получите вердикт, подробное описание шагов и изображение с отмеченными сколами.

## Советы по съёмке

- Одинаковое расстояние до инструмента, зафиксированная камера.
- Один ракурс для всех фото.
- Равномерное освещение без бликов.
- Однородный светлый фон (обрезка фона в `prepare_dataset.py` рассчитана на тёмный инструмент на белом).

## Ограничения и точность

Датасет небольшой: исходных фотографий мало, поэтому обучение проводилось на
**аугментированной выборке**. Каждое фото размножается скриптом `augment_dataset.py`
(оригинал, зеркальное отражение, поворот на 180°, зеркало + поворот), а для YOLO
фото с дефектами дополнительно дублируются (`OVERSAMPLE` в `prepare_dataset.py`).
Аугментация увеличивает число примеров, но не добавляет новой информации: это
по-прежнему одни и те же инструменты и одни и те же сколы.

Что из этого следует:

- Метрики (точность EfficientNet, mAP YOLOv8, графики в `training_results/`) получены на
  малой валидационной выборке и **носят предварительный, демонстрационный характер**.
- Если копии одного и того же фото попадают и в обучающую, и в валидационную выборку,
  метрики получаются завышенными: модель «узнаёт» уже виденный кадр, а не обобщает.
  Для честной оценки выборку нужно делить по исходным фото до аугментации.
- Модель обучена на одном типе инструмента, одной камере и одинаковых условиях съёмки
  (см. «Советы по съёмке»). На других инструментах, освещении и фонах качество может
  заметно упасть.
- Результат приложения стоит считать вспомогательным, а не заменой контроля качества
  человеком.

Чтобы улучшить результат, нужно больше **разных** исходных фотографий (особенно
с дефектами), а не больше аугментированных копий.

## Готовые веса YOLOv8

В `weights/best.pt` лежат веса детектора сколов, обученные на авторском датасете
(один класс: `chip`). Использовать их отдельно от приложения можно так:

```python
from ultralytics import YOLO

model = YOLO("weights/best.pt")
results = model.predict("photo.jpg", conf=0.35, iou=0.45, imgsz=1280)
results[0].save("result.jpg")
```

Чтобы использовать их внутри приложения, скопируйте файл в `DataAI/model_weights/best.pt`.
Приложению также нужен классификатор EfficientNet (`DataAI/model_weights/classifier.pth`),
он создаётся при обучении на вашем датасете (кнопка «Переобучить»), поэтому для полного
двухступенчатого анализа датасет понадобится.
